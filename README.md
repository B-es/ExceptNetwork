# ExceptNetwork

Десктопное Windows-приложение для добавления адресов в исключения прокси-сервера.

## Возможности

- Записывает список адресов в системный параметр `ProxyOverride`
- Показывает список адресов, которые будут добавлены в исключения
- Загружает адреса из файла `nets.txt` при запуске
- Позволяет выбрать файл с адресами вручную через диалог открытия файла
- Поддерживает разделители `;`, `,` и перевод строки, пробелы допускаются
- Показывает справку об автоматической загрузке адресов в отдельном окне

## Хранение исключений

| Параметр | Значение |
|---|---|
| Раздел реестра | `HKEY_CURRENT_USER` |
| Путь к ключу | `Software\Microsoft\Windows\CurrentVersion\Internet Settings` |
| Имя значения | `ProxyOverride` |
| Тип значения | `REG_SZ` |

При сохранении прежние адреса в `ProxyOverride` заменяются новыми.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Формат файла с адресами

Приложите к программе файл `nets.txt` — адреса из него загрузятся автоматически при запуске.

Адреса перечисляются через `;`, `,` или перевод строки, пробелы допускаются:

```
vk.com, yandex.ru
vk.com; yandex.ru
```

## Зависимости

- `customtkinter` — GUI на Tkinter
- `tkinter-tooltips` — всплывающая подсказка на кнопке сохранения
- `pillow` — загрузка иконки выбора файла
- `nuitka` — компиляция в исполняемый файл

## Сборка в .exe

```bash
python build_s.py
```

Сборка выполняется через Nuitka в режиме `--onefile` с иконкой `assets/icon.ico` и встроенной папкой `assets`; результат помещается в `dist`.

## Структура проекта

| Путь | Назначение |
|---|---|
| `main.py` | Точка входа |
| `proxy_exception_adderer.py` | Запись исключений в реестр Windows |
| `tk_ui/app.py` | Окно приложения, список адресов, окно справки |
| `tk_ui/build_page.py` | Сборка и запуск окна приложения |
| `build_s.py` | Параметры сборки и метаданные приложения |
| `nets.txt` | Адреса для автоматической загрузки |

## Требования

- Windows
- Python 3.10+

## Примечание

Если параметры прокси-сетей открыты, результат не появится — необходимо закрыть и снова открыть данные параметры.
